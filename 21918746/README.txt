An Atlas of Short Linear Motif-Mediated Human Protein-Protein Interactions - ASHI - Datasets

A proteome-scale map of SLiM recognition generated by screening >800 human protein domains against HD2, a million-peptide IDR library, reveals >20,000 motif–domain interactions. The Atlas of SLiM-mediated Human protein-protein Interactions (ASHI), highlights widespread, versatile, and multivalent peptide recognition across classical peptide-binding modules, enzymes, chaperones, and RNA-binding proteins.

=========[ file: HD2.tar.gz ]=========
Compressed TSV table of the Human Disorderome 2 (HD2) library design (published originally in Benz et al., 2022 - doi: 10.15252/msb.202110584. PMID: 35044719).

Columns details:
protein_accession: Uniprot Accession identifier of the protein
protein_gene_name: Protein gene name in Uniprot
protein_name: Protein name in Uniprot
protein_organism: Organism the protein belongs to (Human in this case for all proteins)
peptide: Amino acid seqence of the 16 amino acids design peptide
peptide_phage_variant: Amino acid sequence in the synthesised library (cysteines are mutated to alanines)
peptide_start: Amino acid seqence start position according to the Uniprot entry
peptide_stop: Amino acid seqence stop position according to the Uniprot entry

=========[ HD2_SIMBA_raw_results.tar.gz ]=========
Compressed TSV table of the raw data for all SIMBA experiments.

Columns details:
oligo_ID: Unique ID number for each library oligo
peptide: peptide sequence
peptide_oligo: oligonucleotide sequence encoding the peptide
accession: UniProt accession code of the parent protein
gene_name: gene name of the parent protein
protein_name: parent protein name
peptide_start: start position of the peptide in the parent protein
peptide_end: end position of the peptide in the parent protein
type: experimental origin/application of the peptide (Controls, ProP-PD, MoMaP, SLiMSearch, Ala scanning, DMS, Flank swap )
source: origin of the peptide sequence
annotation: additional notes on the peptide features
category: categorical grouping for data analysis
PDZ_category: designates if peptide is derived from PDZ binder in ProP-PD (PDZ); if not, assigned as non-binder (nb_pdz)
PTB_category: designates if peptide is derived from PTB binder in ProP-PD (PTB); if not, assigned as non-binder (nb_ptb)
RRM_category: designates if peptide is derived from RRM binder in ProP-PD (RRM); if not, assigned as non-binder (nb_rrm)
counts: number of Illumina sequencing reads for the indicated bait strain, replicate, and time point: "{bait strain}_{replicate}_{time point}_counts"
z-score: calculated z-score based on comparison to nonbinder control oligos: "{bait strain}_{replicate}_z-score_vs_{nonbinder control set}" (Lib1) or "{bait strain}_{replicate}_z-score" (Lib2)
SIMBA-score: SIMBA score calculated from z-scores of 3 synonymous oligos in 2 replicates (median bait – median Cln2): "{bait strain}_SIMBA-score_vs_{nonbinder control set}" (Lib1) or "{bait strain}_SIMBA-score" (Lib2)
SD: standard deviation calculated from z-scores of 3 synonymous oligos in 2 replicates for each bait strain: "{bait strain}_SD_vs_{nonbinder control set}" (Lib1) or "{bait strain}_SD_vs_{nonbinder control set}" (Lib2)
